# swapd

Multi-provider account switcher for AI coding CLIs (Claude Code, Codex,
Kiro, Gemini, Grok, …). One static Go binary, `--json` on every verb,
provider drivers behind a neutral core. Built as the engine behind
[Infinitus](https://infinitus.run); usable on its own from a terminal.

Design: `docs/superpowers/specs/2026-09-09-swapd-design.md`.
